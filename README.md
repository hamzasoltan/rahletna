نسخة كاملة من المشروع مع إصلاح واجهة الشريك والربط.

## أهم الإصلاحات
- أزرار الانتقال إلى صفحة الشريك مرتبطة مباشرة بحالة التطبيق.
- زر الرجوع للرئيسية داخل صفحة الشريك.
- زر إنشاء كود الدعوة واضح ويعرض حالة التحميل.
- زر نسخ كود الدعوة مع رسالة نجاح/فشل.
- خانة كود الدعوة وزر الانضمام في صف منظم ومتجاوب.
- حالة انتظار الطرف الآخر ظاهرة بوضوح.
- تحسين تنسيق كارت ربط الشريك وصفحة الشريك على الموبايل والكمبيوتر.

## التشغيل
احتفظ بملف `.env.local` الخاص بك في جذر المشروع، ثم:

```bash
npm install
npm run dev
```

متغيرات البيئة المطلوبة:

```env
VITE_SUPABASE_URL=...
VITE_SUPABASE_PUBLISHABLE_KEY=...
```

لا يوجد SQL جديد مطلوب لهذا التعديل.

### V2.6 — Date/Timezone Bug Fix

تم إصلاح مشكلة اختفاء المهمة المضافة في «اليوم» بسبب استخدام `toISOString()` (UTC) مع تواريخ يومية تعتمد على التوقيت المحلي.

- كل تواريخ اليوم أصبحت Local Date Keys بصيغة `YYYY-MM-DD`.
- إضافة أدوات `dateKey`, `addDaysKey`, `monthStartKey`, `nextMonthStartKey`, `monthEndKey`.
- إصلاح Dashboard و Smart Dashboard و History و Habit Manager و Streak.
- تحميل مهام الشهر أصبح من أول الشهر الحالي حتى أول الشهر التالي.
- لا يوجد استخدام متبقٍ لـ `toISOString().slice(0,10)` في كود الواجهة.
