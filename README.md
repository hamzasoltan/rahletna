# رحلتنا — أفضل نسخة من نفسي 🌱

## V2.6 — التكرار اليومي للأهداف والعادات

- 🎯 أهداف بمدة زمنية (مثل شهر) مع خطوات تتكرر يوميًا.
- 📅 كل إنجاز لخطوة هدف يُحفظ لكل يوم بشكل مستقل.
- 📊 عرض إنجاز اليوم والتقدم الكلي للهدف.
- 🌱 العادات تدعم اختيار أيام التكرار، مع سجل مستقل لكل يوم.
- ⚡ تحديثات Realtime لبيانات الأهداف والعادات وسجلات الإنجاز.

> مثال: هدف لمدة 30 يومًا + 3 خطوات = 3 خطوات جديدة قابلة للإنجاز كل يوم، بدون أن يؤثر إنجاز أمس على إنجاز اليوم.

## التشغيل

```bash
npm install
npm run dev
```

أنشئ `.env.local` وضع مفاتيح Supabase في متغيرات `VITE_SUPABASE_URL` و`VITE_SUPABASE_PUBLISHABLE_KEY`.

قبل استخدام V2.6 نفّذ migration:
`supabase/migrations/006_v2_6_daily_goal_steps.sql`
